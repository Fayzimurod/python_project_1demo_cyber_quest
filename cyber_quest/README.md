# ⚡ CyberQuest 2077: Neo-City Escape

Текстовая киберпанк RPG-игра в терминале с цветным интерфейсом, процедурными событиями, прокачкой и сохранением прогресса.

## 🚀 Особенности
- **Zero Dependencies**: Написана на чистом Python 3 без установки сторонних библиотек.
- **Цветной CLI UI**: Динамический вывод с цветовой индикацией статуса и эффектом печати.
- **Боевая система**: Пошаговый бой с различными типами врагов и предметами.
- **Сохранение и загрузка**: Автоматическая сериализация состояния игрока в JSON.
